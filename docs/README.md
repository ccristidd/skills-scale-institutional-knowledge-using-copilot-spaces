# OctoAcme Project Management Docs

A central index and brief summary of OctoAcme's project management process documents. Use this page as the single entry point for understanding our approach and navigating to the detailed guidance in this repository.

## Project management processes summary

OctoAcme uses a lightweight, iterative project management approach focused on delivering customer value in small, testable increments. Work starts with project initiation, where the team validates the problem, identifies stakeholders, defines success metrics, and makes a go/no-go decision using a Project One-pager. Once approved, planning breaks the initiative into a prioritized backlog with acceptance criteria, clear ownership, milestone dates, and a Definition of Done so the team can move from idea to execution with shared expectations.

During execution, the team uses a project board and defined delivery rhythms to manage work through daily standups, weekly syncs, and demos. Pull requests are kept small when possible, include links to issues and acceptance criteria, and must pass CI and review requirements before merging. The workflow is designed to maintain visibility across engineering, product, and stakeholders while enabling fast feedback and controlled delivery.

Communication and risk management are built into the process. Each project tracks stakeholders, risks, and dependencies in simple artifacts such as a risk register and status updates, with escalation paths that move from the team to the PM, Product Lead, and Sponsor as needed. Release and deployment follow a standard checklist with smoke tests, rollback planning, security validation, and post-deploy verification to reduce operational risk. After each sprint, release, or major milestone, the team runs a retrospective to capture learning, assign action items, and continuously improve the way it works.

- Keep the project artifacts updated in the `docs/` folder of this repository.

1. Review the overview and choose the document that matches your current project phase.
